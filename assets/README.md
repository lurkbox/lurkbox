# Lurkbox artwork

Art direction B, "Late-night couch". Everything is generated by `assets/src/build-art.py`; run `python3 assets/src/build-art.py` (it needs `rsvg-convert`).

| File | Size | Steam grid file (`~/.local/share/Steam/userdata/<id>/config/grid/`) |
|---|---|---|
| `steam/capsule.png` | 600×900 | `<appid>p.png` |
| `steam/wide.png` | 920×430 | `<appid>.png` |
| `steam/hero.png` | 3840×1240 | `<appid>_hero.png` |
| `steam/logo.png` | transparent | `<appid>_logo.png` |
| `steam/icon.png` | 256×256 | `icon` field in shortcuts.vdf |
| `icons/NxN.png` | 16–512 | app icon (`linux.icon` in `apps/desktop/electron-builder.config.js`, the Flatpak manifest in `apps/desktop/flatpak/`, the desktop window icon) |

The `assets/` folder is shared by the apps. The desktop app packs `icons/`, `steam/` and `src/wordmark.json` into the AppImage (see `apps/desktop/src/main/paths.js`); `steam/` is also the original art that "Restore original Lurkbox art" and `apps/desktop/scripts/deploy-steammachine.sh` use; the core loads `src/wordmark.json` from its host at `/vendor/wordmark.json` to draw themed Steam art.

The wordmark is set in Bricolage Grotesque ExtraBold and stored as outlines in `src/wordmark.json`. The font is licensed under the SIL Open Font License; see `src/BricolageGrotesque-OFL.txt`. The decky-steamgriddb plugin can still replace any of these after install.
