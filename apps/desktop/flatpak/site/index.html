Lurkbox

A couch and controller client for Twitch, as a Flatpak

Install

Install Lurkbox

Open the downloaded io.github.lurkbox.Lurkbox.flatpakref with KDE Discover (or GNOME Software) and choose Install. The Freedesktop runtime and the Electron base come from Flathub, which is added for you if it isn't set up yet.

Or from a terminal:

flatpak install --user https://lurkbox.github.io/lurkbox/io.github.lurkbox.Lurkbox.flatpakref

Then start it from the app menu, or with flatpak run io.github.lurkbox.Lurkbox.

Updates

The install adds this repository as the remote lurkbox. New releases show up in Discover's updates like any other app, or with flatpak update. To add only the repository: lurkbox.flatpakrepo.

Good to know

  • This is Lurkbox's own repository, not Flathub. Commits and the summary are signed with the key lurkbox-flatpak.gpg (fingerprint 5A11 8BD9 DB64 1F63 0D2B 277C E5F9 F45D 5EB9 FC46).
  • The first start copies an existing AppImage profile from ~/.config/Lurkbox; after that the Flatpak keeps its own in ~/.var/app/io.github.lurkbox.Lurkbox/.
  • Sandbox limits (Floater audio, the Decky plugin bridge) are listed in docs/flatpak.md. For Floater in Game Mode, the AppImage is still the better fit.
  • Uninstall: flatpak uninstall --user io.github.lurkbox.Lurkbox (add --delete-data to remove its profile).
